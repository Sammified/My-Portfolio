Rules:
- Best: photos you take of real owners, with their written permission to appear on the Tiera website.
- Stock photos: only with a licence that covers commercial use, and never present the person as a Tiera customer.
- The site labels these "Illustrative stories, not Tiera customers". Keep that label.

Missing files are fine: each card falls back to a designed gradient.
For the Netlify preview, put the same files in a `photos/` folder next to `index.html`.
